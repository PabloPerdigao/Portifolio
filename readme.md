# Bem-vindo(a) ao meu portifólio!

 Este é o meu portfólio pessoal, desenvolvido para apresentar um pouco da minha trajetória, ferramentas e habilidades técnicas utilizadas nos projetos desenvolvidos.

 ![preview-portifolio](assets/images/preview-portifolio.gif)

## Visão geral

O projeto é uma página web estática, responsiva e com navegação por seções. A experiência inclui:

- Hero section com efeito de chuva Matrix em Canvas;
- Apresentação pessoal e assinatura interativa;
- Lista de tecnologias e habilidades técnicas;
- Galeria de projetos com links para repositórios, demonstrações e protótipos no Figma;
- Links de contato para LinkedIn, GitHub, e-mail e WhatsApp;
- Download do currículo em PDF.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Bootstrap 5;
- Bootstrap Icons;
- Font Awesome;
- Google Fonts;
- Canvas API.

## Estrutura do projeto

```text
Portifolio/
├── index.html             # Página principal
├── script.js              # Interações e animação Matrix
├── CSS/
│   └── styles.css         # Estilos e responsividade
└── assets/
    ├── files/             # Currículo e outros arquivos
    ├── fonts/             # Fontes locais
    └── images/            # Logos, fotos e imagens do portfólio
```

## Como executar

### Abrir diretamente no navegador

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em um navegador moderno.

### Usar um servidor local

Com o VS Code, instale a extensão **Live Server**, abra o projeto e selecione **Open with Live Server** no arquivo `index.html`.

Também é possível usar um servidor estático disponível no ambiente, por exemplo:

```bash
npx serve .
```

O projeto não exige instalação de dependências ou processo de build. Os recursos de Bootstrap, ícones e fontes são carregados por CDN, portanto a conexão com a internet é necessária para que todos os elementos visuais sejam exibidos corretamente.

## Personalização

- Edite o conteúdo das seções e os links de projetos em `index.html`;
- Ajuste cores, tipografia, layout e responsividade em `CSS/styles.css`;
- Altere a animação Matrix e os comportamentos interativos em `script.js`;
- Substitua imagens e o currículo dentro de `assets/images` e `assets/files`;
- Atualize os links de contato no rodapé da página.
